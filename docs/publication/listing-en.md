# Listing texts (English)

## Name

WeAdU UTM Ledger

## Short description (manifest, 250 characters max)

Build campaign URLs, flag links missing utm_source, utm_medium, or utm_campaign, and keep a Markdown ledger. Local only.

## Long description

WeAdU UTM Ledger helps you build and review campaign URLs without leaving your notes.

- Insert UTM URL: fill in the landing URL, source, medium, campaign, and optionally content and term. The URL is inserted at the cursor.
- Ledger: add each URL you build as a dated row in a "UTM ledger" table in the current note.
- Check UTM links: list every link in the note and flag a missing, repeated, or empty utm_source, utm_medium, or utm_campaign.
- Defaults: save a default source, medium, and campaign in the settings.

Values are lowercased and may contain letters, digits, and . _ ~ - with no spaces. Existing UTM parameters are replaced; other parameters are kept.

The plugin makes no network request and has no telemetry. Free and open source (MIT), made by WeAdU.
