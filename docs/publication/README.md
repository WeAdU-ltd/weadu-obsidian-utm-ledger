# Publication kit: WeAdU UTM Ledger

Texts for the WeAdU team member who posts by hand. Nothing here is posted automatically.

| File | Content |
| --- | --- |
| `listing-en.md` | Directory listing texts in English (short description and long description). |
| `listing-fr.md` | The same texts in French, for reference and for French-speaking communities. |
| `post-en.md` | Short announcement for the Obsidian Forum, ready to copy. |
| `post-fr.md` | French version of the announcement. |
| `instructions-maricar.md` | Where to post, the rules to follow, and how to handle replies (English and French). |
| `checklist.md` | What has to be done before anything is posted. |

Do not post anything until the WeAdU team confirms that the plugin is published and sends the public link. Replace `LINK` with that link.
